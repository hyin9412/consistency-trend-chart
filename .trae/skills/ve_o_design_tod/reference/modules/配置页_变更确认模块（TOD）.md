# 配置页变更确认模块

## 一、使用组件

- **必要准则**：若业务补充规则里提及了使用某个业务场景组件，则以业务补充规则里提及的组件为准。否则使用下述组件。
- 变更确认模块使用组件库中的表格组件（如`Table`）和状态标签组件（如`Tag.TagPro`），属性配置规则遵循各组件的属性能力。

## 二、使用场景

- 配置页多步流程的最后一步（如 ConfigStepModal 的"变更确认"步骤），供用户在提交前对比前后配置差异。
- 弹窗/抽屉内展示配置变更 diff 信息。

## 三、模块组成

-   **分区标题**：按配置分组展示标题（如"默认配置"、"IDC 独立配置"），标题文字使用 `--color-text-1` 色值
-   **变更类型标签**：每组 diff 需标注变更类型，使用 `Tag.TagPro` 展示
-   **Diff 表格**：每组变更使用独立的 `Table` 展示前后差异

## 四、基础布局

### Diff 分组结构

- 按配置维度分组，每组包含：分组标题 + 变更类型标签 + Diff 表格
- 分组之间纵向间距 16px
- 分组标题与标签水平排列（flex），标签紧随标题右侧，间距 8px

### Diff 表格列定义

根据变更类型使用不同的列结构：

| 变更类型 | 列数 | 列定义 |
|---------|------|--------|
| 修改 | 3 列 | 配置项（width: 120px）、变更前、变更后 |
| 新增 | 2 列 | 配置项（width: 120px）、新增内容 |
| 删除 | 2 列 | 配置项（width: 120px）、删除内容 |

### 变更类型标签

使用 `Tag.TagPro` 组件，通过 `type` prop 指定语义色，`icon={null}` 去掉默认图标：

| 变更类型 | `type` 值 | 展示文案 |
|---------|----------|---------|
| 新增 | `success` | 新增 |
| 修改 | `warning` | 修改 |
| 删除 | `error` | 删除 |

### 表格属性

- 使用 default 尺寸（不传 `size` prop）
- `border={true}` 展示边框
- `pagination={false}` 不分页

## 五、通用交互规范

### 1. Diff 计算规则

- 按唯一标识（如 IDC 名称）做 key 匹配，判断新增/删除/修改
- 新旧配置中均存在的 key，逐字段对比值是否变化，变化则标记为"修改"
- 仅在新配置中存在的 key 标记为"新增"
- 仅在旧配置中存在的 key 标记为"删除"

### 2. 空状态

- 当前后配置完全一致时，展示"无配置变更"提示文案，居中展示

### 3. 操作流程

- 变更确认为只读展示，不可编辑
- 用户确认 diff 无误后点击"提交"按钮完成操作
- 用户可通过"上一步"按钮返回编辑步骤修改配置
