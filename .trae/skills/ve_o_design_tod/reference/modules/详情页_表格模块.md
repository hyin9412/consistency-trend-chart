# 详情页表格模块规范

## 一、使用组件

- **必要准则**：若业务补充规则里提及了使用某个业务场景组件，则以业务补充规则里提及的组件为准。否则使用下述组件。
- 表格模块使用组件库中的表格组件（如`Table`），属性配置规则遵循 `Table` 组件的属性能力。

## 二、模块组成

表格模块由 3 个主要部分组成：

1. **标题栏区**：必须包含，标题栏撑满整行，标题文本在左，操作按钮组在右侧且右对齐。
   - **标题文本**：必须使用14px字号，加粗显示，距离内容区 12px，不可使用 Title 的预设档位。
   - **操作按钮组**：可配置，不超过 2 个，使用 `secondary button` 样式。
2. **表格区**：必须包含，且表格撑满整行，位于标题栏下方。
3. **自定义内容：可根据用户需求（图片或文字描述），自主理解并添加相关内容**
4. **筛选区 (可选)**：若用户有对表格数据有筛选、操作的需求，可使用对应的筛选区组件，如 `SearchForm`、`Filter`、`toolbar` 等。

## 三、基础布局

该部分定义了表格在页面中的视觉骨架和基本展示规则。

- **模块标题**：必须包含模块标题（如设备信息、人员信息等）。
- **响应式规则**：表格横向需始终撑满页面，列宽支持动态调整。
- **表格行高**：如无特别说明，表格行密度保持默认（标准密度），避免因自定义 `padding` 造成不一致。
- **表格行数**：默认展示10行数据。
- **按钮配置**：
  - **数量限制**：不超过 2 个。
  - **样式要求**：必须使用 `secondary button`，严禁使用 `primary button`。
  - **典型操作**：编辑、保存、导出、全部下载。
  - **按钮右对齐**：让 title 最外层容器占满可用宽度（ flex: 1 或 width: '100%' ），再把按钮/按钮组设置 marginLeft: 'auto' 推到最右侧。


## 四、通用交互规范

### 1. 基础交互规则

定义了用户在操作表格时的行为逻辑与系统反馈。

- **只读和编辑状态切换**：所有信息默认使用只读态组件；若用户点击"编辑"按钮，实现编辑/保存逻辑。
- **状态切换流**：
  1. 点击右上角"编辑"按钮。
  2. 按钮切换为"保存"，所有字段从只读态转为编辑态。
  3. 点击保存后，字段数量保持一致，更新最新信息。
  4. 系统弹出 Toast 提示："修改完成"。
- **数据溢出处理**：当宽度超过列宽时，文本截断并显示省略号，Hover 后通过 `tooltip` 展示完整信息。
- **表格横向滚动**：尽量避免表格内容换行；当表格实际内容宽度超过显示宽度时，表格可横向滚动。
- **操作列规则**：若有操作列，必须固定在表格最右侧。
- **Tab切换**：表格模块中可添加 Tab，用以切换不同维度的表格内容，Tab 样式为 `capsule`，上下 margin 为 12px。
- **筛选区规则**：如果详情页表格区域需要筛选，可使用 筛选区 组件，横向排列，默认折行显示筛选区选择组件，需要有"全部"选项，且必须放在第一个位置。


### 2. 组件映射关系表

根据数据类型，只读态与编辑态使用的组件对应如下（仅限表格模块）：

| **数据类型**             | **业务场景**          | **只读态组件**                                                                                       | **编辑态组件**                  |
| :------------------- | :---------------- | :---------------------------------------------------------------------------------------------- | :------------------------- |
| **文本 (Text)**        | 标题、名称、单位、布尔值等常规信息 | 直接显示文本（如：编号、标题、名称等）。列宽建议 240px，超出后"..."省略，不允许换行。                                                | `Input` 输入框组件              |
| **数值 (Number)**      | 数量、距离、重量等         | 直接显示文本（如：数量、距离、重量等）。**右对齐**；列宽建议 100px；单位跟在数值后。                                                 | `Input` 输入框组件              |
| **金额 (Money)**       | 用于展示货币金额          | 直接显示文本（如：¥12,500）。**必须保留百分位**；默认 150px；不允许换行。                                                   | `Input` 输入框组件              |
| **人员 (User)**        | 用于描述人员、人名信息       | `Avatar` 头像组件 + 姓名（如张海、吴敏、John White等）。取用户名首字符，英文自动转大写，中文直接取首字。展示头像+名字；超过 2 个展示"+n"；Hover 显示卡片。 | `Select` 下拉选择组件，可复选        |
| **时间 (Date)**        | 用于描述时间点信息         | 时间字符串（如：2024/10/25）。推荐格式：`YYYY-MM-DD HH:mm:ss`；默认 220px。                                        | `DatePicker` 日期选择器         |
| **时间范围 (Daterange)** | 用于描述时间区间信息        | 格式：`YYYY-MM-DD - YYYY-MM-DD`；默认 220px。                                                          | `DatePicker range` 日期区间选择器 |
| **变更信息**             | 数据前后对比            | 不省略、不换行；展示原值与新值对比。                                                                              | `diff` 组件                  |
| **枚举 (Dict)**        | 用于描述 2 个以上的同类型信息  | 文本或标签组（如：CPU、GPU、服务器等）                                                                          | 带删除功能的标签组或选择器              |
| **状态 (status)**      | 用于描述状态信息          | `Tag` 标签组件（如进行中、已完成、已暂停等）                                                                       | `Select` 下拉选择组件            |

### 3. 校验与异常处理

定义了数据输入阶段的错误处理规则。

- **校验触发**：点击"保存"按钮后进行全量校验。
- **校验内容**：包括必填项漏填及信息格式错误。
- **视觉反馈**：校验结果（错误信息）以**红字**形式显示在对应输入项的正下方。
- **空值处理**：当字段信息缺失时，统一展示为符号 `"-"` 作为兜底。
- **附件展示**：默认显示 1 条；超过 2 个显示"+n"，Hover 展示全部。
