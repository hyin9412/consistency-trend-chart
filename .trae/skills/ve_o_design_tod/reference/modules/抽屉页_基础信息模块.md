# 抽屉页基础信息模块规范

## 一、使用组件

- **必要准则**：若业务补充规则里提及了使用某个业务场景组件，则以业务补充规则里提及的组件为准。否则使用下述组件。
- 基础信息模块使用组件库中的基础信息组件（如`description`），属性配置规则遵循 `description` 组件的属性能力。

## 二、模块组成

模块由 2 个主要部分组成：

1. **标题区**：必须包含模块标题。
2. **信息区**：必须包含的区域，用于展示具体的业务数据。

## 三、基础布局

- **间距规则**：在 Grid 布局中严格保证"列宽相等"且"内容不撑开列宽"，若超出列宽需截断内容并显示省略号，Hover 悬停显示 Tooltip 完整信息；若不超出，则无需截断内容。
- **布局类型**：使用流式布局。

## 四、通用交互规范

### 1. 组件映射关系表

根据数据类型，只读态与编辑态使用的组件对应如下（仅限基础模块区域）：

| **数据类型**  | **意图**               | **只读态组件**                                                       | **编辑态组件**                               |
| :-------- | :------------------- | :-------------------------------------------------------------- | :-------------------------------------- |
| **文本/数字** | 用于描述编号、金额等信息         | 直接显示文本（如：CP9384023、¥12,500）                                     | `Input` 输入框组件                           |
| **时间/日期** | 用于描述时间信息             | 时间字符串（如：2024/10/25）                                             | `DatePicker` 日期选择器                      |
| **人员**    | 用于描述人员信息             | `Avatar` 头像组件 + 姓名（如张海、吴敏、John White等）。取用户名首字符，英文自动转大写，中文直接取首字。 | `Select` 下拉选择组件                         |
| **地址**    | 用于描述地址信息             | 详细地址文本（如：中国浙江省杭州市）                                              | `SFormAddressInput` 地址输入组件              |
| **枚举/品类** | 用于描述 2 个以上的同类型信息     | 文本或标签组（如：CPU、GPU、服务器等）                                          | 带删除功能的标签组或选择器                           |
| **状态**    | 用于描述状态信息             | `Tag` 标签组件（如进行中、已完成、已暂停等）                                       | 选项 > 3 使用 `Select`；选项 ≤ 3 使用 `Radiobox` |
| **附件**    | 用于描述文件信息             | 文件名链接（如：供应商列表.xls）                                              | `Upload` 上传组件                           |
| **图片**    | 用于显示图片               | 图片缩略图（尺寸 80\*80）                                                | 带上传功能的图片组件                              |
| **特殊信息**  | 用于描述特殊信息，点击后出现弹窗解释详情 | 文字链 `link`                                                      | `Select` 下拉选择组件                         |

### 2. 响应式自适应规则

根据抽屉宽度，组件响应式调整每行字段数非默认值2，而是跟断点绑定，信息区根据屏幕宽度（w）自动调整每行显示的字段数量：

| **屏幕宽度 (w)** | **colNumber值** |
| :----------- | :------------- |
| xxxl         | 5 个            |
| xxl          | 4 个            |
| xl           | 4 个            |
| lg           | 3 个            |
| md           | 2 个            |
| sm           | 2 个            |
| xs           | 1 个            |

### 3. 组件规则

## 1. 核心属性总览

| 核心属性           | 设计规则                               |
| :------------- | :--------------------------------- |
| 模块标题（必填）       | - 显示模块名称（设备基础信息）等                  |
| 标题栏右侧的按钮区域（选填） | - 可显示针对模块操作的按钮（如编辑、导入、导出等）         |
| 标签文案与长度        | - 确保标签一行展示，尽量不换行                   |
| 标签与内容的排布方向     | 默认纵向排布 `vertical`                  |
| 内容超长省略         | 需要显示内容易超出（如长 IP/路径/描述）：开启省略跨视图切换按钮 |
| 内容为空时的占位       | - 默认为"-"，需要强调"未填写"：可替换为 未填写 / 暂无   |

### 4. 交互规则

定义了该模块的交互规则。

- **编辑/保存**  ：
    - 标题模块撑满行，右侧可配置"编辑"按钮。点击后按钮变为"保存"，同时下方基础信息模块从只读态切换为编辑态。
    - 点击"保存"后，系统更新修改信息，并弹出 Toast 提示"修改完成"。
    - 校验内容包括必填项漏填及信息格式错误。
    - 同一行内每个 Item 的输入控件左对齐且宽度与该 Item 内容列等宽；不出现"输入框只占一小段、右侧留大片空白"的情况。
- **可点击的信息**  ：
    - 信息字段设置为 `link`，点击后触发 `抽屉组件`。
    - `link` 一般不可编辑，若需要可编辑，则只能为枚举值，通过 `Select` 组件进行选择。
- **标签强制不换行**  ：
    - 若标签文案过长，则显示省略号，hover可显示完整文案；不要换行处理。
- **基础信息展示样式**  ：
    - 默认使用无边框展示。
