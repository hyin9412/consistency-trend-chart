# 列表页页面标题模块规范

## 一、使用组件

- **必要准则**：若业务补充规则里提及了使用某个业务场景组件，则以业务补充规则里提及的组件为准。否则使用下述组件。
- 页面标题模块使用组件库中的标题组件（如`PageHeader`），属性配置规则遵循 `PageHeader` 组件的属性能力。

## 二、模块组成

页面标题模块可根据实际需求，配置不同的信息展示方式，常见属性可根据不同组件库进行适配，以下为通用建议：

| 常见属性                    | 使用场景                    | 设计规则       | 
| :-------------------- | :----------------------- | :----------- |
| `title`               | 详情页标题（必填）           | - 可显示订单号（C3909283）、页面名（设备信息管理）等   |
| `subTitle`            | 副标题（选填）         | - 可显示备注信息（如更新时间：2025-08-15 10:00:00）   | 
| `backIcon`            | 返回按钮 | - 默认不显示；仅在"从其他页面进入详情"的路径下开启 |
| `extra`               | 标题右侧操作按钮（选填）         | 根据用户需求进行配置     |
| `tab`                 | 跨视图切换按钮（选填）         | 需要显示跨视图切换按钮 |
| `breadcrumb`          | 面包屑（选填）        | - 页面层级 ≥ 2 时展示面包屑。  | 

- **按钮**：标题栏右侧可添加操作按钮，最多可添加3个按钮，间距为12px。

## 三、通用交互规范

### 1. 返回导航交互

- **触发条件**：当用户从其他页面（如列表页）跳转进入详情页时，需配置 `backIcon` 和 `onBack` 属性。
- **交互行为**：点击返回图标，默认返回上一页
- **隐藏规则**：当详情页为顶层入口页面（非从其他页面跳转进入），无需显示返回按钮。

### 2. 面包屑导航交互

- **触发条件**：页面层级 ≥ 2 时展示面包屑，通过 `breadcrumb` 属性配置。
- **层级建议**：面包屑层级不超过 3 级，最后一级为当前页面，不可点击。

### 3. 标题右侧操作按钮交互

- **触发条件**：在标题栏右侧放置可操作按钮（如"编辑"、"删除"、"导出"等）。
- **交互规则**：
  - 按钮数量建议不超过 3 个，主操作使用 `primary` 类型，次要操作使用 `secondary` 类型，按钮间距 12px。
  - 按钮超过 3 个时，展示前 2 个高频按钮，其余通过"更多"下拉菜单收纳。
  - 危险操作（如删除）使用 `danger` 状态按钮，点击后需弹出二次确认弹窗。

### 4. 标题旁标签交互

- **触发条件**：通过 `tags` 属性在标题旁展示状态标签（如"运行中"、"已过期"等）。
- **交互行为**：标签为只读态，仅用于信息展示，不可点击操作。状态变更时标签自动更新颜色和文案。
