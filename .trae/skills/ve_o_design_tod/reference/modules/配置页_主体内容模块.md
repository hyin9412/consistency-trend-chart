# 配置页主体内容模块

## 一、使用组件

- **必要准则**：若业务补充规则里提及了使用某个业务场景组件，则以业务补充规则里提及的组件为准。否则使用下述组件。
- 主体表内容模块使用组件库中的表单组件（如`Form`），属性配置规则遵循 `Form` 组件的属性能力。

## 二、模块组成

-   **Alert提示**：（可选）主要用于 Alert 信息提示。展示于表单的上方。
-   **residentContent**：（可选）用于展示表单常驻辅助信息或操作按钮或锚点，常见的形式有配置预览卡片与锚点，描点适合用于长表单。
-   **表单内容区域**：（必选）核心区域，主要是由表单组件构成。

## 三、基础布局

- **间距规则**：在 Grid 布局中严格保证"列宽相等"且"内容不撑开列宽"，若超出列宽需截断内容并显示省略号，Hover 悬停显示 Tooltip 完整信息；若不超出，则无需截断内容。
- **布局类型**：使用流式布局。

### 布局结构：

- **带左导航 + 表单内容区域 + residentContent**：表单内容宽度固定 680px，居中布局；右侧 residentContent 宽度 133px，居右对齐；适合上下 Label 结构的表单。使用场景：需要展示左侧导航的配置页面、表单配置项数量超过 2 屏以上。
- **表单内容区域 + residentContent（较窄宽度）**：表单内容宽度固定 796px，居中布局；右侧 residentContent 宽度 133px，居右对齐；适合上下 Label 结构的表单。使用场景：不需要左侧导航、不包含复杂表单配置项、表单配置项数量超过 2 屏以上。
- **表单内容区域 + residentContent（较宽宽度）**：整页宽度 1260px，整体左右结构；表单内容宽度 970px，居左对齐；residentContent 区域多展示配置预览卡片，max 宽度 274px，居右对齐。使用场景：不需要左侧导航、包含复杂表单配置项。
- **仅有表单内容区域**：表单内容宽度固定 1260px，居中布局；适合左右 Label 结构的表单。使用场景：不需要左侧导航、包含复杂表单配置项、表单配置项数量少于 2 屏。

## 四、通用交互规范

### 1. 交互规则

-   **联动操作**：支持某个字段变化触发其他字段显隐、值变化、异步请求等
-   **提交行为**：需要考虑提交、取消、下一步、上一步等按钮点击后流程交互
   -   **提交**：在多步骤场景，「提交」按钮展示在最后一步，点击「提交」进行校验，校验成功后弹出文案提示，根据业务场景，可返回至配置发起页面或者配置结果的详情页面；校验失败，弹出提示引导用户
   -   **取消**：点击「取消」，弹出二次确认
   -   **上一步**：点击「上一步」，支持用户返回至上一步，注意保存当前步骤的草稿数据
   -   **下一步**：点击「下一步」进行校验，校验成功直接进入下一步配置页面，校验失败，弹出提示或者在配置页面提示引导用户
-   **步骤条交互**：需要考虑跳转拦截与回调，流程控制、校验阻断及引导体验
-   **锚点**：超出2屏高度的长表单可以支持锚点交互，点击锚点跳转至对应的位置
-   **离开二次确认**：需要考虑防丢失体验

### 2. 校验与错误文案

注意校验及触发时机，请提供符合业务场景的错误文案，校验类型如下：

| 校验类型     | 规则说明                             |
| ------------ | ------------------------------------ |
| **必填**     | 是否是必填项校验                     |
| **格式**     | 邮箱/手机号/URL等                    |
| **数值范围校验** | 最大值、最小值、必须是整倍数等       |
| **长度校验**   | 最小或最大长度校验                   |
| **一致性校验** | 本地化、统一的语气及提示位置的一致性 |

| 装饰器类型                 | 属性及使用场景                                     | 案例                                         |
| -------------------------- | -------------------------------------------------- | -------------------------------------------- |
| **anchor** 锚点组件        | 用于长表单，支持用户快速导航                       |                                              |
| **Resident 区域-自定义内容** | 展示表单常驻辅助信息/操作按钮。                    | 价格配置预览卡片，包含价格、下单操作按钮等     |
