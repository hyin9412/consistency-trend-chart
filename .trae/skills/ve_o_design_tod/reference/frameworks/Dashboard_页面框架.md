# Dashboard 页面框架规范

## 一、页面框架组成

- **必要准则**：若业务补充规则里提及了使用某个框架组件，则以业务补充规则里提及的组件为准。否则使用下述组件。
- 若用户需要看核心数据、关键功能和状态监控，则可以使用 Dashboard 页面（如控制台、工作台、数据看板页面等），由标题区域和内容区域两部分组成。

### 页面标题区域 (Page Header)

- **位置**：位于页面框架的最顶部
- **作用**：明确告知用户当前页面名称、类型、所处的具体位置等信息，起到 **承上启下** 的作用。

### 内容区域 (Content Area)

- **基于通用看板思路设计dashboard**
- **位置**：位于页面标题区域下方
- **特征**：它是页面中 **面积最大、信息密度最高** 的矩形区域，承载详情页的主要信息。
- **样式**：通常由卡片式模块组成，每个模块之间有明显的分隔。

## 二、通用设计规范

-   页面背景色为 `#FFFFFF`。
-   内容区域各个模块之间卡片式分隔，卡片边界与容器两侧对齐。
-   加载并使用源力图表组件来展示数据图表
-   同一行卡片的高度必须一致
