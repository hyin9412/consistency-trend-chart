# 表单规范

内部平台表单设计的通用规范。基于 `Form`（`@tod-m/materials/ve-o`）构建。

| **使用场景** | **对应组件的交互样式** |
| :--- | :--- |
| 标准表单布局 | 使用 `Form` + `Form.Item`，Label 左对齐，输入区域定宽 |
| 必填标识 | 必填字段 Label 前带红色 `*` 标识（`rules` 中 `required: true`） |
| 字段说明 | Label 右侧使用 `IconQuestionCircle` + Tooltip/Popover 提供字段解释 |
| 表单校验 | 失败时输入框红色描边 + 下方红色提示文案；提交时触发全量校验 |
| 表单分组 | 多个字段逻辑分组时使用标题分隔（如"基础信息"/"高级配置"），组间距 24px |

> 业务约束：
> - 同一表单内 Label 宽度保持一致，通常 80-120px；Label 宽度根据当前表单中最长 Label 的文字数量来判断，确保所有 Label 右对齐后输入区域左侧对齐；
> - 输入框宽度按内容类型确定：短文本 264px、长文本 480px、全宽 100%；
> - 帮助文案使用白色 Popover 承载（多行/列表型内容），不使用黑色 Tooltip；
> - 表单提交按钮文案使用"确定"/"提交"/"创建"等明确动词，不使用"OK"/"Submit"等英文。
