# 状态展示

内部平台状态字段展示的规范。基于 `Tag.TagPro`（`@tod-m/materials/ve-o`）构建。

| **使用场景** | **对应组件的交互样式** |
| :--- | :--- |
| 列表页状态列（高密度） | 使用 `Tag.TagPro`，通过 `type` prop 指定语义状态色（如 `success`="运行中"、`error`="已停止"） |
| 详情页状态强调 | 使用 `Tag.TagPro`，视觉自带语义色圆点 + 文字 |
| 操作结果/审核状态 | 使用 `Tag.TagPro`，`type` 自动关联预置图标与配色 |
| 配置变更 diff 标签 | 修改用 `warning`、新增用 `success`、删除用 `error` |

> 业务约束：
> - 状态标签统一使用 `Tag.TagPro`（非基础 `Tag`），`type` prop 合法值：`success`、`warning`、`error`、`stop`、`loading`、`spin`、`processing`；
> - 禁止使用基础 `Tag` 的 `color` prop（如 `blue`、`arcoblue`、`orangered`）来表达业务状态；
> - 同一业务状态在列表页和详情页的 `type` 必须保持一致；
> - 状态文案使用业务可识别的中文短语（"运行中"/"已停止"/"创建中"），禁止直接透出后端枚举值（如 `RUNNING`）；
> - 异常/失败状态需提供补充信息：hover 或点击可查看失败原因；
> - 同一表格内仅使用一种状态展示形态，不混用。
