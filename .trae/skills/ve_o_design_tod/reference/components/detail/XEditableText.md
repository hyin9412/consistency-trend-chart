# XEditableText 行内编辑

内部平台中行内可编辑文本的规范。基于 `XEditableText`（`@tod-m/materials`）构建。

| **使用场景** | **对应组件的交互样式** |
| :--- | :--- |
| 表格内备注/描述编辑 | 点击编辑 icon 后弹出气泡确认框，内含输入框，确认后提交 |
| 详情页字段编辑 | 字段值右侧展示编辑 icon（灰色），hover 时 icon 可见，点击进入编辑态 |
| 只读态 | `showEditIcon={false}` 时不展示编辑 icon，纯文本展示 |
| 长度限制 | 通过 `max` 属性限制最大字符数 |

> 业务约束：
> - 编辑操作需区分权限：无编辑权限时隐藏编辑 icon（非置灰）；
> - 编辑气泡标题使用"修改 + 字段名"格式（如"修改备注"）；
> - 提交失败时保留用户输入内容并展示错误提示，不自动清空。
