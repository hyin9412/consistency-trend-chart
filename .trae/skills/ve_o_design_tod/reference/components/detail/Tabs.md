# Tabs 选项卡

内部平台 Tab 切换的规范。基于 `Tabs`（`@tod-m/materials/ve-o`）构建。

源力设计体系中 Tabs 组件的类型分类（非层级关系，彼此独立）：
- **L1 一级选项卡**：页面顶层内容切换，带底部高亮线
- **L2 二级选项卡**：页面内子模块切换，带底部高亮线，视觉比 L1 轻量
- **L3 三级选项卡**：更细粒度切换，纯文字无底部线
- **Capsule 胶囊选项卡**：胶囊圆角背景样式，适用于局部内容筛选/切换
- **Rounded 圆角选项卡**：圆角矩形背景样式
- **Vertical 纵向选项卡**：竖向排列
- **Multi-line 多行选项卡**：多行带副标题

| **使用场景** | **对应组件的交互样式** |
| :--- | :--- |
| 页面主内容区切换（全局 Tab） | 使用 `type="card-gutter"` 样式（对应 L1 一级选项卡），Tab 之间有间隔，视觉突出 |
| 页面内局部内容筛选/切换 | 使用 `type="capsule"` 胶囊样式（对应 Capsule 胶囊选项卡），紧凑轻量 |
| 简洁线条 Tab | 使用默认 `type="line"` 样式（对应 L2/L3 选项卡），适用于弹窗/抽屉内的内容切换 |

> 业务约束：
> - 同一页面不同层级的 Tab 样式必须区分：页面级用 `card-gutter`（L1），内容区局部切换用 `capsule`（胶囊）或 `line`（L2/L3），禁止同层级混用；
> - 胶囊选项卡（`capsule`）必须位于左侧展示，不得右对齐；当胶囊 Tab 与筛选项/操作按钮同行时，Tab 靠左、筛选/按钮靠右；
> - Tab 切换仅刷新对应内容区，页面标题/筛选栏等公共区域保持不变；
> - Tab 项数量控制在 2-7 个，超过应使用其他导航形式（如侧导航分组）；
> - Tab 标题使用短名词（2-4 字），禁止使用完整句子。
