# XSearchForm 筛选表单

内部平台列表页筛选栏的规范。基于 `XSearchForm`（`@tod-m/materials`）构建。

| **使用场景** | **对应组件的交互样式** |
| :--- | :--- |
| 标准筛选栏 | `XSearchForm` + `XSearchForm.Item` 组合，每个字段独立一项 |
| 字段前缀标签 | 使用 `addBefore` 属性在输入框/选择器前展示字段名称标签，宽度 264px |
| 非内联布局 | `inline={false}` 时筛选项换行排列，适用于筛选条件较多（≥4 个）的场景 |
| 值变化即搜索 | 通过 `onValuesChange` 监听筛选值变化后自动触发查询 + 重置分页 |
| 手动搜索模式 | 筛选条右侧放置"查询"+"重置"按钮，用户主动点击触发查询 |

### 筛选栏布局适配规则

筛选栏采用 24 栅格 Grid 进行适配，margin 为 32px，gutter 为 12px，行间距 12px。

**场景 A：无胶囊 Tab 时（纯筛选栏）**

筛选器占据整行宽度，按栅格划分列。适配规则：
- 单个筛选器最小宽度 285px，最大宽度 332px；
- 筛选器数量 ≤ 当前行可容纳数时，一行排列，右侧放"高级筛选"按钮（如有）和操作按钮；
- 筛选器数量超出当前行可容纳数时，超出部分收纳进"高级筛选"展开面板（第二行）；
- 当屏幕宽度变化时，筛选器跟随栅格自适应宽度。

屏幕宽度对应：
| 屏幕宽度 | 内容区宽度 | 单行可容纳筛选器数（参考） |
| :--- | :--- | :--- |
| 1280px | 1080px | ~3 个 |
| 1440px | 1240px | ~4 个 |
| 1920px | 1720px | ~5-6 个 |

**场景 B：有胶囊 Tab 时（Tab + 筛选同行）**

胶囊 Tab 位于最左侧，剩余空间按栅格划分给筛选器和操作按钮，所有内容在同一行：
- 布局：`[胶囊 Tab] [筛选器...] [高级筛选按钮（如有）] [操作按钮]`；
- 胶囊 Tab 宽度由内容撑开，不参与栅格计算；
- 筛选器在胶囊 Tab 右侧的剩余空间内按栅格排列；
- 超出剩余空间的筛选项收纳进"高级筛选"；
- 操作按钮固定在最右侧。

> 业务约束：
> - 筛选项优先级从左到右排列：高频筛选 → 低频筛选；超过一行的低频项可收纳进"高级筛选"；
> - `Select` 类筛选项必须有"全部"选项或 `allowClear` 支持清空，禁止无法取消筛选的死锁状态；
> - 重置按钮点击后恢复所有筛选项的默认值，同时触发一次查询；
> - 同一列表页的筛选项数量控制在 2-6 个，超过 6 个应使用折叠面板或高级搜索；
> - "高级筛选"展开面板为带背景色（`var(--color-bg-3)`）的区块，展示在筛选栏下方、表格上方，内部筛选项同样按栅格排列。
