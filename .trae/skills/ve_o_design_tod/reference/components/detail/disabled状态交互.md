# disabled 状态交互

内部平台中不可操作状态的交互规范。

| **使用场景** | **对应组件的交互样式** |
| :--- | :--- |
| 按钮禁用 | 按钮置灰 + `cursor: not-allowed`；hover 触发黑色 Tooltip 展示禁用原因 |
| 表单字段禁用 | 输入框/选择器灰色底 + 不可交互；需在字段下方或 Tooltip 说明禁用原因 |
| 表格操作项禁用 | 操作文字灰色 + hover Tooltip 说明（如"默认项目不可删除"） |
| 菜单项禁用 | 菜单项灰色文字，hover 说明禁用原因 |

> 业务约束：
> - 所有 disabled 状态必须提供原因说明，禁止仅置灰不解释；
> - 禁用原因文案使用"原因 + 解决方案"格式（如"余额不足，请先充值"）；
> - 批量操作场景下，部分项可操作部分项不可时，操作按钮保持可用，提交时仅处理可操作项并提示跳过原因。
