# 提示与反馈

内部平台中操作反馈的规范。

| **使用场景** | **对应组件的交互样式** |
| :--- | :--- |
| 操作成功 | 使用 `Message.success` 全局轻提示，2s 后自动消失 |
| 操作失败 | 使用 `Message.error` 全局轻提示，展示错误摘要；详细错误在相关位置内联展示 |
| 需要关注的提示（非阻塞） | 使用 `Alert`（info/warning 类型）内联在相关内容上方 |
| 危险操作确认 | 使用 `Modal.confirm`，标题为"确认 + 动作"，内容说明影响范围 |
| 加载中 | 按钮点击后切换为 loading 态，防止重复提交；页面级加载使用骨架屏 |

> 业务约束：
> - 成功提示文案格式："动作 + 成功"（如"创建成功"/"删除成功"）；
> - 失败提示需包含可操作信息，禁止仅展示"操作失败"无后续；
> - 危险操作确认弹窗的确认按钮使用红色 `status="danger"`，取消按钮在左；
> - 同一操作不同时使用 Message 和 Notification，选择一种即可。
