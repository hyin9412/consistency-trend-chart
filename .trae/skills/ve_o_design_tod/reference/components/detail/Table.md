# Table 表格

内部平台列表页表格的规范。基于 `Table`（`@tod-m/materials/ve-o`）构建，各 app 可在此基础上做业务封装（如 TableX）。

**组件选用**：列表页主表格使用 `Table` 或业务封装表格组件（如 TableX）；详情页/弹窗/抽屉内的小数据集附属表格直接使用基础 `Table`，不引入额外的工具栏/筛选/分页等噪音。

| **使用场景** | **对应组件的交互样式** |
| :--- | :--- |
| 标准列表页表格 | `Table` + 分页器 + 行选择（可选）；列宽自适应，操作列固定右侧 |
| 批量操作 | 勾选行后表格上方/下方出现批量操作栏，展示"已选 N 项"+ 操作按钮；使用 `rowSelection` 配置 |
| 空状态 | 使用 `XEmpty`（`@tod-m/materials`）作为 `noDataElement`，文案根据场景定制 |
| 表格内嵌链接 | 可跳转的字段使用 Link 样式（蓝色 + hover 下划线），点击跳转对应详情页 |
| 操作列 | 固定右侧，文本按钮形式；操作项 ≤ 3 个直出，> 3 个收纳为"更多"下拉 |
| 表格排序 | 列头支持点击排序（升序/降序/默认），排序图标在列头文字右侧 |
| 自定义分页 | 通过 `renderPagination` 自定义分页区域，可在分页器旁添加"跳至"、"条数切换"等能力 |

> 业务约束：
> - 操作列中的危险操作（删除/停用）必须使用红色文字，且点击后弹出二次确认；
> - 时间列统一不换行，宽度固定 180px，格式为 `YYYY-MM-DD HH:mm:ss`；
> - 表格加载中统一使用 `loading` 属性的骨架屏效果，禁止自定义全屏 Loading 遮罩；
> - 单元格内容超长统一尾部省略 + hover Tooltip 展示完整内容；
> - 空状态文案根据场景区分："暂无数据"（无数据）/"未找到匹配结果"（筛选无结果）；
> - Table 统一使用 default 尺寸（不传 `size` prop），禁止在弹窗、抽屉等容器内自行降级为 `size="small"` 或 `size="mini"`，仅当单行高度有明确设计稿标注时才可覆盖；
> - 批量操作栏必须在勾选行后出现在页面底部（吸底固定），使用 `FixedFooter` 组件实现；内容为"已选 N 条"文字 + "取消选择"文本按钮 + 操作按钮组；禁止将批量操作按钮直接放在筛选栏或表格上方；
