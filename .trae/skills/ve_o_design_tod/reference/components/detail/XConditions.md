# XConditions 条件组

内部平台中 AND/OR 逻辑关系表达的规范。基于 `XConditions`（`@tod-m/materials`）构建。

| **使用场景** | **对应组件的交互样式** |
| :--- | :--- |
| 条件关系可视化 | 使用 `XConditions.Relation` 展示 AND/OR 逻辑连接线 |
| 可编辑条件组 | `XConditions.Relation` 嵌入 `Form.Item` 中，支持切换 AND/OR |
| 只读展示 | 设置 `isView={true}`，仅展示逻辑关系不可编辑 |
| 嵌套条件 | 支持多层嵌套，每层通过缩进和连接线视觉区分层级 |

> 业务约束：
> - 条件嵌套深度不超过 3 层，超出应简化表达或使用其他交互形式；
> - AND/OR 切换时需保留已配置的条件内容，仅改变逻辑关系；
> - 条件组为空时展示"添加条件"入口按钮，不展示空的连接线。
