# TOD 物料库组件清单

组件选型优先级：`@tod-m/materials`（X 系列） > `@tod-m/materials/ve-o`（基础 UI） > `@arco-design/web-react`（兜底）

| XCard | 卡片 |
| XList | 列表 |
| XTree | 树 |
| XActionGroup | 操作按钮组 |
| XActionList | 操作列表 |
| XEmpty | 空状态 |
| XCopy | 复制 |
| XTextLink | 文本链接 |
| XOverflowText | 溢出省略文本 |
