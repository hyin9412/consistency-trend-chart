# 总览趋势图设计契约

## 规范映射清单

- 页面框架命中：Dashboard 页面框架，使用全局顶部导航 + 左侧导航 + 主内容区。
- 模块命中：页面标题模块、方案 Tabs 模块、指标/数据取值/商品/计费单元/大区筛选模块、趋势图卡片模块。
- 组件命中：`PageHeader.PageHeaderPro`、`Tabs`、`Card`、`Select`、`Radio.Group`、React-VChart `VChart`。
- 核心功能命中：方案一保留归档版总览趋势图；方案二复刻目标趋势图方案的最终方案，增加商品、计费单元和大区选择器，图表维度为商品 × 计费单元 × 大区。
- 交互闭环命中：指标/数据取值/商品/计费单元/大区多选实时更新图表；方案二支持单图聚合/多图拆分切换、legend 点击排除、hover focus icon 仅展示、多图同账期 tooltip 联动、锁定 tooltip 后同步滚动和多图拖拽排序。

## 页面结构

- 标题：总览趋势图。
- 标题描述：商品为 Bytegraph / ByteNDB / Mysql / CACHE / Abase，口径为商品 × 计费单元 × 大区 × 月，图表组件为 VChart。
- 内容区：`padding: 20px 32px 24px`，模块间距 16px。
- 方案切换：`方案一：archive` 展示旧版总览图；`方案二：最终方案` 默认展示新版最终方案。
- 方案二筛选区：包含指标多选、数据取值多选、商品多选、计费单元多选、大区多选、时间选择和单图聚合/多图拆分切换；数据取值选项为实际值、目标值，默认实际值；商品选项为 Bytegraph、ByteNDB、Mysql、CACHE、Abase；计费单元选项为 ByteGraph CPU、bytegraph.mem、ByteGraph 存储，默认全选；大区选项为 cn、ap、sg、va，默认 cn；时间默认 2026-08，可切换过去 6 个月。
- 方案二图表区：单图聚合使用目标趋势图方案最终方案的大卡片，灰框高度固定 `360px`；多图拆分按指标生成多张卡片并支持拖拽排序，每个指标图表灰框高度固定 `280px`；底部分页 legend 默认展示为 `商品名称, 计费单元|大区`，最多展示两行，只有超过两行需要分页时才显示右侧分页器，hover 图例项时右侧显示“仅展示”图标，点击后仅保留该项；legend 两行时应在卡片内部自动压缩上方图表主体高度，不占用卡片底部间距；图表 legend/tooltip 中计费单元展示时省略 `bytegraph` 前缀，筛选器选项保留原文。

## 图表规范

- 商品通过颜色区分：Bytegraph、ByteNDB、Mysql、CACHE、Abase。
- 实际值使用实线，目标值使用虚线；图表右上角展示线型图例。
- 方案二单图聚合：价格类指标走左 Y 轴，百分比指标走右 Y 轴，左右轴使用相同主刻度数量，右轴每条 grid 线均展示对应数值且标签垂直居中；legend 文案为 `商品名称, 计费单元|大区, 指标`，颜色按指标区分。
- 方案二多图拆分：每个指标一张图，legend 文案为 `商品名称, 计费单元|大区`，标题行与图表主体间距为 `12px`。
- X 轴和 Tooltip 标题均按月展示为 `YYYY-MM`，不展示到具体日期；Y 轴根据指标单位自动格式化。
- 时间为 2026-08 时每条数据只展示单个点，不展示折线连接；实际值为实心圆点，目标值为空心虚线圆点。
- Y 轴主刻度强制为 5 个以降低网格密度，网格线使用 `--color-border-2` 与虚线样式；Y 轴范围按刻度步长规整并关闭 VChart 自动 nice 扩展，使 hover 灰色定位线顶部与最上方 grid 齐平；方案二单图聚合 Tooltip 使用目标趋势图方案同款列表样式，12px 字号、20px 行高和紧凑行距，实际值 marker 为 10×10 方块且圆角 1.54px，目标值 marker 使用 10px 宽同色虚线。
- 方案二多图拆分点击任一图表账期后锁定所有图表同账期 tooltip；同行图表 tooltip 保持相同纵向位置；时间为 2026-08 的单点模式下，所有可见 tooltip 统一保持在 hover 线同一侧，并根据视口空间自动选择左侧或右侧；滚动任一已锁定 tooltip 内容时，其他可滚动 tooltip 同步上下滚动。
