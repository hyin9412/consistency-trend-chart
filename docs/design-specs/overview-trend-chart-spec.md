# 总览趋势图设计契约

## 规范映射清单

- 页面框架命中：Dashboard 页面框架，使用全局顶部导航 + 左侧导航 + 主内容区。
- 模块命中：页面标题模块、方案 Tabs 模块、指标/商品筛选模块、趋势图卡片模块。
- 组件命中：`PageHeader.PageHeaderPro`、`Tabs`、`Card`、`Select`、`Radio.Group`、React-VChart `VChart`。
- 核心功能命中：方案一保留归档版总览趋势图；方案二复刻目标趋势图方案的最终方案，增加商品选择器，并将原 `[计费单元 × 大区]` 维度替换为商品名称。
- 交互闭环命中：指标/商品多选实时更新图表；方案二支持单图聚合/多图拆分切换、legend 点击排除、hover focus icon 仅展示、多图同账期 tooltip 联动和多图拖拽排序。

## 页面结构

- 标题：总览趋势图。
- 标题描述：商品为 Bytegraph / ByteNDB / Mysql / CACHE / Abase，口径为商品 × 月，图表组件为 VChart。
- 内容区：`padding: 20px 32px 24px`，模块间距 16px。
- 方案切换：`方案一：archive` 展示旧版总览图；`方案二：最终方案` 默认展示新版最终方案。
- 方案二筛选区：包含指标多选、商品多选、时间选择和单图聚合/多图拆分切换；商品选项为 Bytegraph、ByteNDB、Mysql、CACHE、Abase。
- 方案二图表区：单图聚合使用目标趋势图方案最终方案的大卡片；多图拆分按指标生成多张卡片并支持拖拽排序。

## 图表规范

- 商品通过颜色区分：Bytegraph、ByteNDB、Mysql、CACHE、Abase。
- 实际值使用实线，目标值使用虚线；图表右上角展示线型图例。
- 方案二单图聚合：价格类指标走左 Y 轴，百分比指标走右 Y 轴；legend 文案为 `[商品] 指标`，颜色按指标区分。
- 方案二多图拆分：每个指标一张图，legend 文案为商品名称，标题与卡片间距沿用目标趋势图最终方案。
- X 轴按月展示为日期粒度，Y 轴根据指标单位自动格式化。
- 网格线使用 `--color-border-2` 与虚线样式；方案二单图聚合 Tooltip 使用目标趋势图方案同款列表样式，12px 字号、20px 行高和紧凑行距，目标值 marker 使用同色虚线。
