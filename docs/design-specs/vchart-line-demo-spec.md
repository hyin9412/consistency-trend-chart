# VChart 折线图示例页 - 设计契约

- 核心优化点：新增一个轻量 Dashboard 风格示例页，直接验证 `@visactor/react-vchart` 在当前工程中的接入方式。
- 核心优化点：页面结构保持 TOD 二级页范式，包含 `PageHeader.PageHeaderPro`、分隔线、卡片式内容区。
- 核心优化点：图表区内置 30 个组件的 mock 趋势数据，默认仅展示 Top5 低一致率组件。
- 核心优化点：图表标题改为普通文本标题，不使用蓝色小竖杠强调样式。
- 核心优化点：图表区新增两个无边框选择器与全屏按钮，Legend 下置并使用方块图例，支持选择器与 legend 联动；切到 `Top5 高一致率组件` 时，legend 按一致率从高到低排序展示。

## 页面架构结论

该页面匹配 `Dashboard_页面框架`，属于二级示例看板页面，用于承载单一主题的趋势图演示。

## 设计视角

### 页面级布局结构

- 左侧导航 + 右侧内容区
- 页头使用 `PageHeader.PageHeaderPro`，标题下方紧跟 `Divider`
- 内容区域 padding 为 `20px 32px 24px`
- 内容模块采用卡片式分隔，模块间纵向间距 `16px`

### 模块清单

#### 模块 1：页面标题区

- 业务功能：说明当前页面是 VChart 折线图示例页
- 推荐组件：`PageHeader.PageHeaderPro`
- 交互规范：展示标题及 3 个简短描述项，不放置全局操作按钮

#### 模块 2：概览指标区

- 业务功能：快速展示累计推量、日均推量、峰值日期
- 推荐组件：`Card`
- 布局规范：三列卡片并排，小屏自动折成单列

#### 模块 3：折线图区

- 业务功能：展示组件一致率趋势，内置 30 个组件供 legend 自定义勾选
- 推荐组件：`Card` + `VChart`
- 交互规范：图表渲染失败时使用 `Message.error` 提示；支持通过全屏按钮切换浏览器全屏；右上角第一个选择器默认选中 “Top5 低一致率组件”，切换到 “Top5 高一致率组件” 时默认展示高一致率 Top5，并将 legend 按一致率从高到低排序；用户若手动改动 legend 勾选结果且不再匹配预设 Top5 集合，则该选择器回填为 “请选择”
- 样式规范：图表区高度 360px，图表卡片与绘图区背景为纯白色，标题使用普通文本样式；Legend 位于图表下方，图例形状为方块

## 产品视角

### 页面目标

- 给当前工程补一个可直接访问的图表示例页
- 为后续接真实接口、增加筛选器或扩展更多图表类型提供基础模板

### 用户路径

1. 从左侧菜单进入 “VChart 折线图”
2. 页面顶部确认当前场景与数据口径
3. 先看上方 3 个概览指标，再看下方折线趋势

### 边界规则

- 当前数据全部为 mock 数据
- 页面不承载筛选、下载、联动等复杂交互
- 当前仅验证 legend 勾选、Top5 预设切换、时间范围切换和全屏能力，不引入额外接口逻辑

## 规范映射清单

- 页面框架命中：`Dashboard_页面框架.md`
- 模块命中：页面标题模块、概览指标模块、图表展示模块
- 组件命中：`PageHeader.PageHeaderPro`、`Card`、`Select`、`Button`、`VChart`
- 核心功能命中：新页面可访问、菜单可进入、30 个组件趋势可渲染、Top5 预设可联动 legend
- 交互闭环命中：图表渲染异常有错误提示

## Mock 数据说明

- 统计周期：支持近 7 日、近 14 日、近 30 日和项目开始至今
- 指标口径：30 个组件的一致率趋势，默认展示 Top5 低一致率组件
- 数据用途：用于演示 VChart 多折线图、legend 勾选与外部筛选预设联动方式
