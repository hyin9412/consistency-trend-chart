# CloudEChart 折线图示例页 - 设计契约

- 核心优化点：新增一个轻量 Dashboard 风格示例页，验证 `CloudEChart` 在当前工程中的接入方式。
- 核心优化点：沿用 TOD 二级页范式，保持 `PageHeader.PageHeaderPro`、分隔线、卡片式内容区结构不变。
- 核心优化点：完整搬运“组件一致率趋势”的核心交互，包括 Top5 预设切换、时间范围切换、全屏和最多 10 个组件选择限制。
- 核心优化点：图表主体使用 `CloudEChart`，自定义底部 legend 以保证交互能力和选择上限约束稳定可控。

## 页面架构结论

CloudEChart 折线图示例页基于 Dashboard 二级页面范式进行实现，属于单图表趋势演示页面。

## 1. 页面整体架构

- 页面布局结构：
  - 左侧导航 + 右侧上下结构（标题区 + 内容区）
- 页面样式规范：
  - 页面背景为 `var(--color-bg-1)`
  - 内容区域 padding：`20px 32px 24px`
  - 模块纵向间距：`16px`
  - 页面标题区吸顶，标题下方保留分隔线

## 2. 模块清单及详细定义

### 模块 1：页面标题区

- 业务功能：展示页面标题与图表场景摘要
- 推荐组件：`PageHeader.PageHeaderPro` + `Divider`
- 核心功能建议：标题展示 `CloudEChart 折线图示例`，摘要字段展示场景、图表库和数据来源

### 模块 2：概览指标区

- 业务功能：展示当前所选组件的平均一致率、最高单点、最低单点
- 推荐组件：`Card`
- 布局/样式规范：三列卡片并排，小屏自动折为单列；主数字使用 28px

### 模块 3：趋势图与控制区

- 业务功能：展示组件一致率趋势，并支持 Top5 预设、时间范围切换、全屏和自定义 legend 选择
- 推荐组件：`Card` + `CloudEChart` + `Select` + `Button`
- 核心功能建议：
  - 默认展示 Top5 低一致率组件
  - 支持最近一周、最近两周、最近一个月、项目开始至今
  - 支持浏览器全屏
  - legend 放置在图表下方，最多同时勾选 10 个组件
- 交互与避坑约束：
  - 手动勾选结果不再匹配预设集合时，预设选择器回填为“请选择”
  - 超过 10 个组件时禁止继续选中，并展示提示
  - 图表库使用 `CloudEChart`，禁止回退到 VChart

## 3. Mock 数据说明

- 数据范围：30 个组件、90 天一致率 mock 数据
- 默认视图：Top5 低一致率组件
- 数据用途：用于验证 `CloudEChart` 对多折线趋势和外部 legend 交互的承载能力

## 4. 全局代码生成约束 (Coding Constraints)

- 组件优先使用 `@tod-m/materials/ve-o`
- 图表组件使用 `@cloud-materials/charts-common` 的 `CloudEChart`
- 样式使用 SCSS Modules
- 禁止使用 `as any` / `@ts-ignore`
