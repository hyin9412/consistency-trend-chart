# 一致性专项详情页 - 设计契约

- 采用“详情页骨架 + 总览内嵌 dashboard 模块”的组合方式，保证二级页面层级感和总览看板的信息密度同时成立。
- 总览首屏先回答“当前一致率是否达标”，再回答“趋势怎么变”和“问题集中在哪”，信息优先级清晰。
- 折线图与 Top 低一致率组件并列，帮助用户在同一视线范围完成“趋势判断 + 问题定位”。
- 风险概览、通知效果、Top 任务处理人三卡并排，承接核心动作闭环：加急、催办、指派、重发通知。
- PSM 列表与通知记录两个 Tab 保留表格化追踪能力，方便从总览下钻到可执行对象。

## 页面架构结论

本页面匹配 `reference/frameworks/详情页_页面框架.md`，并在“总览”Tab 内嵌 `reference/frameworks/Dashboard_页面框架.md` 的卡片化模块组织方式。

页面类型为二级详情页，使用 `PageHeader.PageHeaderPro + L1 Tabs(card-gutter) + 内容区` 的组合结构。

## 1. 页面整体架构

- 页面布局结构：
  - 左侧导航 + 右侧主内容区
  - 主内容区为：页头区 -> 分隔线 -> 全局 Tab -> Tab 内容区
- 页面样式规范：
  - 页面背景：`#FFFFFF`
  - Tab 内容区 padding：`20px 32px 24px`
  - 总览模块采用卡片式分隔，同一行卡片高度一致
  - 二级页面页头吸顶，内容区随滚动纵向流动
  - 标题下保留分隔线，Tab 与首个模块之间间距 20px

## 2. 页面清单及交互关系

### 页面清单

- 页面名称：一致性专项详情页
- 路由路径：`/consistency-special-detail`
- 页面职责：
  - 展示一致率当前水平、趋势变化、低一致率组件、风险任务、通知效果、处理人负载
  - 提供 PSM 维度与通知记录维度的表格追踪

### 页面内交互关系

- 点击页头返回按钮：返回上一页；若无浏览历史，则回到 `/home`
- 点击总览时间范围按钮：仅刷新趋势图，不影响其他模块
- 点击“放大查看”：打开趋势图放大弹窗
- 点击风险概览/通知效果/处理人列表中的动作按钮：触发对应 mock 交互反馈
- 点击 PSM 列表“查看详情”：查看该组件的进一步信息
- 点击通知记录“查看明细”：查看该批次通知的触达详情

- PSM / 通知记录 -> 表格化追踪对象

## 4. 模块清单及详细定义

### 模块 1：页面标题区

- 业务功能：展示页面名称、专项范围、统计口径、最近更新时间，并提供返回能力
- 推荐组件：`PageHeader.PageHeaderPro`
- 核心功能建议：
  - 使用返回按钮，不使用面包屑
  - `subTitle` 展示专项范围 / 统计口径 / 最近更新时间
- 布局/样式规范：
  - 页头吸顶
  - 标题字号 18px
  - 标题区下方紧接分隔线与全局 Tab

### 模块 2：全局 Tab

- 业务功能：切换“总览 / PSM 列表 / 通知记录”三个视图
- 推荐组件：`Tabs`，`type="card-gutter"`
- 布局/样式规范：
  - 位于页头下方
  - Tab 内容区统一 `padding: 20px 32px 24px`
- 交互与避坑约束：
  - Tab 只刷新对应内容区域，页头保持不变

### 模块 3：一致率进度概览

- 业务功能：优先展示当前一致率，以及与基准一致率、目标一致率的对比关系
- 推荐组件：`Card` + `Progress`
- 核心功能建议：
  - 左侧大号数字展示当前一致率
  - 右侧用进度条展示当前值，并在轨道上打出基准与目标参考线
- 布局/样式规范：
  - 双栏布局：左侧指标、右侧参考进度
  - 参考线文案需与进度轨道对齐

### 模块 4：一致率趋势 + Top 低一致率组件

- 业务功能：
  - 左侧展示不同组件的一致率趋势
  - 右侧展示当前 Top5 低一致率组件
- 推荐组件：
- 趋势区：`Card` + `VChart` 多折线图 + `Modal`
  - Top5 区：`Card`
- 核心功能建议：
  - 时间切换提供：最近一周、最近两周、最近一个月、项目开始至今
  - 图表支持放大查看
  - Top5 展示组件名称和当前一致率
- 布局/样式规范：
  - 两列布局，左宽右窄
  - 同一行卡片高度一致

### 模块 5：风险概览 / 通知效果 / Top 任务处理人

- 业务功能：
  - 风险概览：展示已逾期、DDL <= 1、通知未读 >= 3、无处理人的数量，并支持批量动作
  - 通知效果：展示累计触达、已读率、未读、失败，并提供详情或重发动作
  - Top 任务处理人：展示 Top10 处理人及待处理任务，可逐人催办
- 推荐组件：`Card` + `Button`
- 布局/样式规范：
  - 三列并排布局
  - 每列卡片内部为列表式信息块
- 交互与避坑约束：
  - 动作按钮保持轻量，不抢主视觉

### 模块 6：PSM 列表

- 业务功能：按组件展示一致率、风险等级、待处理任务等明细
- 推荐组件：`Card` + `Table`
- 表格字段建议：
  - PSM
  - 组件名称
  - 处理人
  - 当前一致率
  - 基准一致率
  - 目标一致率
  - 风险等级
  - 待处理任务
  - 最近通知时间
  - 操作
- 布局/样式规范：
  - 表格使用边框模式
  - 支持横向滚动
  - 操作列固定右侧

### 模块 7：通知记录

- 业务功能：记录通知批次、触达范围、阅读和失败情况
- 推荐组件：`Card` + `Table`
- 表格字段建议：
  - 通知批次
  - 通知渠道
  - 触达对象
  - 通知时间
  - 触达人数
  - 已读率
  - 未读人数
  - 失败人数
  - 状态
  - 操作

## 5. 设计视角说明

### 设计目标

- 让用户在首屏快速建立“一致率是否健康”的判断
- 将“趋势判断”和“问题定位”放在同一层级完成
- 降低从看板到动作的切换成本

### 页面心智

- 第一眼：当前一致率是否达标
- 第二眼：趋势是改善还是恶化
- 第三眼：问题主要集中在哪些组件、哪些任务、哪些处理人

### 评审话术

- 这是一个典型的二级详情页，总览不是简单堆指标，而是按“结果 -> 趋势 -> 风险动作”的顺序组织。
- 趋势图右侧直接放低一致率 Top5，可以减少用户在图表和列表之间来回寻找问题对象的成本。
- 下方三张卡片分别对应任务风险、通知闭环、处理人负载，覆盖治理动作所需的核心视角。

## 6. 产品视角说明

### 用户路径

1. 从上游列表进入详情页
2. 在总览 Tab 判断当前一致率和趋势
3. 查看 Top5 低一致率组件定位重点对象
4. 在风险概览、通知效果、Top 任务处理人模块中直接触发动作
5. 切换到 PSM 列表或通知记录，追踪具体对象

### 边界规则

- 当前数据为 mock 示例，实际需要接真实接口
- 趋势图当前已切换为 VChart 多折线图，后续可直接对接真实接口数据与事件能力
- 所有按钮当前为演示交互，需后续接入批量加急、催办、指派与重发通知流程
