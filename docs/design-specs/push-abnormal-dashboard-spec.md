# 推量异常数据看板 - 设计契约

## 页面架构结论
推量异常数据看板基于 `reference/frameworks/Dashboard_页面框架.md` 进行匹配，属于 L2 二级明细看板页面（从商品稽核概览列表页下钻）。

---

## 1. 页面整体架构

- 页面布局结构：左侧导航 + 右侧上下结构（标题区 + 内容区）
- 页面样式规范：
  - 背景色为：`#FFFFFF`
  - 内容区域 padding：`20px 32px 24px`
  - 模块之间纵向间距：`16px`
  - 卡片模块使用 `border-radius: 4px`、`border: 1px solid var(--color-border-2)`
  - 页面使用 Dashboard 卡片式分隔，同一行卡片高度一致

---

## 2. 模块清单及详细定义

### 模块 1：页面标题区 (Page Header)

- **业务功能**：展示"推量异常数据看板"标题及面包屑/返回入口
- **推荐组件**：`PageHeader.PageHeaderPro`
- **核心功能建议**：
  - 标题：推量异常数据看板
  - 标题同一行右侧放置商品 Select 与账期范围组合选择器
  - 不展示静态商品名称、账期范围描述信息
- **布局/样式规范**：
  - 标题字号 18px
  - 商品 Select 与账期范围组合选择器位于 Page title 同行右侧，间距 12px，商品宽度 332px，账期控件宽度 332px
  - 页头吸顶（`position: sticky; top: 0`）

---

### 模块 2：筛选区

- **业务功能**：按当前卡控阶段、商品、账期筛选页面全局数据；稽核明细模块内保留局部筛选
- **推荐组件**：`XSearchForm` 风格的筛选项组合（使用 `Select` + `addBefore`）
- **核心功能建议**：
  - 全局配置筛选：在顶部导航品牌区"字节云"旁边展示"当前卡控阶段" Select
  - 当前卡控阶段：Select 下拉，选项为观察期、软卡、灰度硬卡、硬卡，默认"灰度硬卡"，通过 URL `stage` 参数驱动页面联动
  - 商品筛选：Select 下拉，放置在 Page title 同行右侧，宽度 332px，支持搜索
  - 账期类型：Radio.Group（日/周/月），默认"日"
  - 账期范围：DatePicker.RangePicker
  - 内容区不展示全局筛选块；计费项、稽核结果、PSM、是否入账仅在稽核明细模块内作为局部筛选展示
- **布局/样式规范**：
  - 当前卡控阶段 Select 放在 TopNav 的品牌区内，紧邻"字节云"，高度不超过 28px，不改变原顶部导航 48px 高度
  - 页面内容区不展示计费项、售卖区域、Site、命中规则、最终去向、处理状态、环境、错误码、卡控时机组成的全局筛选卡片
  - 稽核明细模块内筛选项使用 `addBefore` 标签风格，宽度统一 285px，横向排列，gap 12px
  - 账期类型与账期范围作为一个组合输入呈现，整体 32px 高；按日/按周/按月不单独增加外层描边，三个分段项之间不得出现 margin/gap/padding 形成的视觉空白，与后续日期范围选择器之间无间距，选中态仅文字高亮；组合选择器内部字号 13px，字体 Roboto
  - 不展示“更多筛选 / 收起筛选”入口
  - 值变化即时触发筛选，无需"查询"按钮
- **交互与避坑约束**：
  - Select 必须有"全部"选项或 `allowClear`
  - 稽核明细筛选项宽度统一 285px（遵循项目约束），顶栏阶段 Select 使用紧凑宽度
  - 切换"当前卡控阶段"后，重置稽核明细筛选，并联动页面中所有卡控阶段相关展示
  - 阶段联动范围：折叠头当前阶段 Tag、稽核通过率、硬卡/软卡概览卡、稽核明细的"是否入账"和"稽核结果"

### 模块 3：当前卡控阶段与命中规则（折叠面板）

- **业务功能**：展示所选商品当前卡控阶段及生效规则，支持折叠/展开，折叠时头部仍展示当前阶段
- **推荐组件**：`Collapse`（自定义折叠头）+ `Tabs`（type="line"）
- **核心功能建议**：
  - **折叠头**：
    - 左侧蓝标标题"当前卡控阶段与命中规则"，标题使用 `@font-size-title-1`（16px）
    - 标题右侧紧邻展示当前阶段标签（如"硬卡"、"灰度硬卡 | 硬卡采样 20%"），标题文字与阶段 Tag 间距 8px，使用单个 Tag.TagPro；阶段与采样信息中间用 1px 浅色描边竖向分割线分隔
    - Tag 内阶段文本和采样文本分别使用 `text-decoration: underline dashed currentColor` 增加 1px 虚线下划线，分割线本身不加下划线；hover 展示 Tooltip；灰度硬卡 Tooltip 文案为"按设定采样比例部分硬卡，命中采样且不通过的条目会被拦截，不入账。"
    - 折叠/展开箭头在最右侧
  - **展开内容**：
    - 不再重复展示"当前卡控阶段"独立区块，阶段信息仅保留在折叠头右侧
    - **Tabs 切换区**（type="line"）：
      - Tab1：策略规则 - 表格展示 R1-R5 规则、规则含义、管控策略（硬卡/软卡/关闭）、命中计费项；命中计费项为"全部计费项"时展示普通文本，具体计费项按 `、` 拆分后使用线性 Tag 展示，单行展示不下时将剩余项折叠为 `+N` 线性 Tag
      - Tab2：不参与稽核 - 标题后展示不参与稽核站点数量；展示排除配置信息，未配置时显示"未配置排除，全部推量正常参与稽核"
      - Tab3：豁免规则 - 标题后展示被豁免的计费项个数；表格展示计费项、策略规则、账期、豁免前/后、生效/到期时间、剩余时间；策略规则列位于计费项右侧，内容为"规则代号 Tag + 具体规则内容"（如"R1 无有效订单"）；账期列统一展示为 `yyyy-mm-dd ~ yyyy-mm-dd`；豁免前/后仅展示硬卡、软卡、关闭三种策略，支持硬卡变软卡/关闭、软卡变关闭
      - 策略规则表格、豁免规则表格均使用 Table default 尺寸，不传 `size="small"`，保持每行 40px 高度
- **布局/样式规范**：
  - Collapse 头部 padding：`12px 16px`
  - Collapse 内容区 padding：`16px`
  - 页面内所有规则代号 `R1`、`R2`、`R3`、`R4`、`R5` 统一使用 `var(--color-text-2)`，字重 `500`；适用于纯文本、表格单元格、卡片规则行、Tag 文本等所有出现位置
  - 阶段标签颜色映射：观察期=success，软卡=orange，灰度硬卡=orange，硬卡=error；orange Tag 背景色使用 `rgb(var(--oranged-2))`，文字色使用 `rgb(var(--oranged-5))`
  - 管控策略标签颜色映射：硬卡=error，软卡=orange，关闭=default；orange Tag 背景色使用 `rgb(var(--oranged-2))`，文字色使用 `rgb(var(--oranged-5))`；策略规则与豁免规则共用同一套展示口径
  - 当前卡控阶段 Tag 与管控策略 Tag 均传入 `icon={null}`，不展示 TagPro 默认图标
  - 不参与稽核、豁免规则 Tab 标题后使用源力内置 `Tabs.TabsBadge` 展示数字，禁止自定义徽标样式
  - 内部表格使用基础 Table（无分页、无工具栏）
- **交互与避坑约束**：
  - 折叠时必须让用户看到当前卡控阶段是什么
  - 折叠头当前阶段 Tag 需跟随顶部"当前卡控阶段"筛选变化；策略规则表格的管控策略为单条规则配置，仅支持硬卡、软卡、关闭，不跟随顶部卡控阶段派生为观察期或灰度硬卡
  - 默认展示灰度硬卡，切换到观察期/软卡/硬卡后，面板内 Tag 需即时更新
  - 折叠头阶段 Tag 通过 Tooltip 承载阶段说明，不在展开内容区重复展示说明文本
  - 策略规则表格前有信息提示（Alert type="info"）

### 模块 4：推量数据概览

- **业务功能**：展示稽核通过率及各指标概览卡片，硬卡/软卡卡片可点击定位到明细并应用筛选
- **推荐组件**：自定义卡片布局（div + 样式）+ `Tag.TagPro`
- **核心功能建议**：
  - **稽核通过率**：大数字展示百分比，辅助文字说明
  - **硬卡拦截**（1-4 条，动态数量）：
    - 标题：硬卡拦截
    - 总数字
    - 说明："未入账，需优先修复或申请豁免"
    - 下方按规则列出明细（如 R1: 168条, R2: 89条...），每条可点击
    - 卡片整体可点击，点击后定位到稽核明细并筛选"是否入账=否"
    - 卡片左侧红色标识条
  - **软卡告警**（1-4 条，动态数量）：
    - 标题：软卡告警
    - 总数字
    - 说明："已入账但稽核校验不通过，需持续跟进修复"
    - 下方按规则列出明细，每条可点击
    - 卡片整体可点击，点击后定位到稽核明细并筛选"是否入账=是, 稽核结果=软卡告警"
    - 卡片左侧橙色标识条
  - **稽核豁免**：
    - 标题：稽核豁免
    - 数字
    - 说明："N 个生效豁免 · M 个 24h 内到期"
    - 点击定位到明细并筛选"稽核结果=豁免命中"
  - **不参与稽核**：
    - 标题：不参与稽核
    - 数字
    - 点击定位到明细并筛选"稽核结果=不参与稽核"
- **布局/样式规范**：
  - 通过率卡片独占一行左侧（大卡片），或所有卡片使用 grid 布局
  - 硬卡/软卡卡片宽度自适应内容，最小宽度 240px
  - 卡片使用 `background: var(--color-bg-2)`，`border-radius: 4px`，`padding: 16px 20px`
  - 卡片左侧状态条：硬卡=`rgb(var(--danger-6))`，软卡=`rgb(var(--warning-6))`
  - 主数字字号 28px，font-weight 600
  - 规则明细行使用 hover 效果，可点击文字使用 link 色
  - 卡片之间 gap：16px
- **交互与避坑约束**：
  - 硬卡拦截和软卡告警下方的规则条目数量 1-4 条不定，需动态渲染
  - 当前卡控阶段切换后，稽核通过率、硬卡拦截、软卡告警/观察异常的数值和说明需同步变化
  - 点击卡片或规则条目时，页面滚动到稽核明细区域并自动应用对应筛选条件

### 模块 5：稽核明细

- **业务功能**：展示逐条推量稽核记录，支持筛选、排序、导出，并通过侧边栏查看命中规则对应的处理建议
- **推荐组件**：`Table` + `Drawer`（@tod-m/materials/ve-o）
- **核心功能建议**：
  - **表格上方操作栏**：
    - 左侧：模块标题（蓝标）"稽核明细"
    - 不放置导出按钮，导出入口并入筛选栏右侧操作区
  - **筛选栏**（表格上方）：
    - 计费项（Select 多选）
    - PSM（Select 多选/Input）
    - 是否入账（Select：是/否）
    - 稽核结果（Select：校验通过/拦截不入账/软卡告警/观察记录/豁免命中/不参与稽核）
    - 筛选项宽度 285-332px 自适应；1440 屏下四个筛选项优先同排展示
    - 筛选行右侧展示操作区：导出按钮在左，"查看处理建议"按钮在右，两个按钮均使用线性样式
    - 导出按钮使用线性按钮，仅展示下载 icon，通过 Tooltip 说明"导出当前结果"
    - 若四个筛选项已占满一行，操作区另起一行并固定在最右侧；若屏幕较宽且筛选项一行未满，操作区与筛选项同排并靠最右
    - 不展示"重置筛选"按钮
  - **表格列**：
    - 账期开始时间、账期结束时间（合并展示为 `yyyy-mm-dd ~ yyyy-mm-dd` 日期范围，width 220）
    - 商品（width 140）
    - 计费项（width 160）
    - 售卖区域/Site（width 120）
    - 实例（XOverflowText 省略展示，width 200）
    - 服务树路径（XOverflowText，width 200）
    - Customer（width 120）
    - 实例用量（width 120）
    - 推账条目用量（width 120，右对齐）
    - 更新时间（width 180，格式 YYYY-MM-DD HH:mm:ss，支持排序）
    - 是否入账（Tag.TagPro：是=success/否=error，width 100）
    - 稽核结果（Tag.TagPro，width 120，固定在表格右侧）；当结果为"不参与稽核"时，Tag 需带状态 icon，使用源力中表示"暂停/不参与"语义的图标
    - 命中规则和异常结果（width 260，固定在表格右侧）：
      - 常规异常：展示为"规则代码 Tag + 具体规则内容"，如 `R1 Tag + 无有效订单`
      - 豁免命中：不展示规则代码 Tag，展示为 `X 条 豁免规则`，hover 展示具体豁免规则内容
      - 不参与稽核：不展示规则代码 Tag，可展示"不参与稽核，无异常结果"的说明文案
  - **处理建议侧边栏**：
    - 点击筛选行右侧"查看处理建议"按钮打开 Drawer
    - Drawer 内容与 PRD 6.2.5.3"异常结果与处理建议"保持一致，使用卡片列表展示 R1-R5 全量规则
    - 每张卡片展示：命中规则 Tag、异常结果标题、当前筛选结果下的命中条数、处理建议列表
    - Drawer 固定展示 R1-R5 全量规则的异常结果和修复建议原文
- **布局/样式规范**：
  - 稽核明细整体不使用灰色外框和灰底，模块区域直接承载标题、筛选和表格
  - 筛选行与表格之间不加分割线，通过 16px 间距区分
  - 表格使用 border 模式
  - `scroll={{ x: true }}` 支持横向滚动
  - 分页：pageSize 10，showTotal
  - 默认按更新时间倒序
- **交互与避坑约束**：
  - 支持列排序（账期、用量、更新时间）
  - 从数据概览点击卡片时，自动设置筛选条件并滚动到该区域
  - 单元格超长省略 + Tooltip
  - 禁止使用展开子表格/展开行承载命中规则和修复建议
  - 当前卡控阶段切换后，明细中的"是否入账"和"稽核结果"按阶段语义派生展示
  - 导出按钮点击后提示"已创建 N 条记录的导出任务，可在导出中心查看"

## 4. 全局代码生成约束 (Coding Constraints)

- 禁止使用 `as any` / `@ts-ignore`
- 组件从 `@tod-m/materials/ve-o` 导入，不直接用 arco-design（除非该组件 @tod-m/materials 没有）
- 图标使用 `@arco-design/iconbox-react-ve-o-design`
- 样式使用 SCSS Modules，类名使用 camelCase
- 蓝标模块标题使用 CSS `::before` 伪元素实现，参考 Figma `Rectangle 34625398`：3px 宽、16px 高、背景 `rgb(var(--primary-6))`、圆角 `0 4px 4px 0`
- 筛选项统一宽度 285px
- 状态标签统一使用 `Tag.TagPro`，禁止使用基础 Tag 的 color prop；业务要求 orange Tag 时通过 SCSS Modules 覆盖为 `--oranged-2 / --oranged-5`
- 页面内所有规则代号 `R1`、`R2`、`R3`、`R4`、`R5` 的文本样式统一为 `var(--color-text-2)` + `font-weight: 500`，不得按语义色单独改写规则码文字颜色
- 页面整体遵循 TOD 内部平台设计规范中的间距和色彩体系
