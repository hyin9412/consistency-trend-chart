# API 批量打标页面设计契约

## 需求概述

- 页面承载 PRD《API 标签管理与打标功能》中的 API 视图与标签视图。
- 核心目标：
  - 支持全量 API 的统一查询与标签管理。
  - 支持勾选单个或多个 API 后，通过统一弹窗在“批量移除标签”和“批量新增标签”两种模式间切换。
  - 在 UI 层强约束同一 Key 只能选择一个 Value。

## 页面框架映射

- 页面框架命中：`reference/frameworks/列表页_页面框架.md`
- 弹窗框架命中：`reference/frameworks/弹窗_框架.md`

- 表格模块命中：`reference/modules/列表页_表格模块.md`

## 设计规范要点

### ve-o 通用规范

- 页面采用左侧导航 + 右侧内容区。
- 页面标题、全局 Tab、内容区之间保持规范间距。
- 表格操作列固定在右侧，超长内容使用省略与 Tooltip。
- 操作结果统一使用 `Message` 反馈。

### TOD 业务规范

- 页头必须使用 `PageHeader.PageHeaderPro`。
- 全局内容切换使用 `Tabs` 的 `card-gutter` 样式。
- 内容区统一使用 `padding: 20px 32px 24px`。
- 批量操作栏必须使用 `FixedFooter`，通栏吸底展示。
- 弹窗使用 `Modal`，本次批量打标弹窗宽度为 `800px`。

## 模块与组件映射

### 模块 1：页面标题区

- 业务功能：展示“标签管理”页面标题与页面级操作。
- 推荐组件：`PageHeader.PageHeaderPro`
- 核心功能：右侧保留“查看操作记录”入口。

### 模块 2：全局 Tab

- 业务功能：切换 API 视图与标签视图。
- 推荐组件：`Tabs`
- 样式：`type="card-gutter"`

### 模块 3：API 筛选栏

- 业务功能：支持按组件、请求方法、标签、关键词筛选 API。
- 推荐组件：`Select` + `Input` + `Button`
- 交互规则：筛选条件即时生效，不提供单独的“查询 / 重置”按钮。

### 模块 4：API 列表

- 业务功能：展示 API 名称、组件、Method、当前标签，并支持勾选。
- 推荐组件：`Table`
- 关键规则：
  - 列表默认展示全量 API。
  - “当前标签”为空时，即表示未打标。
  - 行操作“打标”默认对当前单个 API 生效。
  - 表格上方仅保留右侧“操作记录”按钮，不展示额外 section title。

### 模块 5：批量操作栏

- 业务功能：展示已选数量，并提供取消选择、批量打标操作。
- 推荐组件：`FixedFooter` + `Button`
- 关键规则：仅在存在勾选时显示，位于页面最外层容器内。

### 模块 6：批量打标弹窗

- 业务功能：统一处理批量新增和批量移除标签。
- 推荐组件：`Modal` + `Alert` + `Radio.Group` + `Tag` + 原生布局容器
- 交互闭环：
  - 顶部展示影响范围提示。
  - 提示条下方增加按钮式模式选择器：
    - `批量移除标签`
    - `批量新增标签`
  - 当模式为“批量移除标签”时：
    - 展示当前选中 API 的标签状态。
    - 标签按“完全包含”和“部分包含”分组展示。
    - 点击标签即可加入待移除列表。
  - 当模式为“批量新增标签”时：
    - 顶部保留“新增标签方案”切换入口，便于评审时在四种新增交互间切换。
    - 仅展示添加标签区域。
    - 支持四种候选方案：
      - `方案 A`：左侧为 Key 列表，右侧为该 Key 下的 Value 单选区域。
      - `方案 B`：仅保留“添加新标签”区域，每一行为 `Key 选择器 + Value 选择器 + 删除`，底部单独提供“添加标签”按钮新增一行。
      - `方案 C`：使用单个可搜索选择器按 `Key:Value` 逐条添加，选择后结果沉淀到“即将新增的标签”区域，已选 Key 在下拉中置灰。
      - `方案 D`：延续方案 B 的多行编辑布局，但“添加标签”按钮点击后打开多选下拉；用户一次勾选 N 个 Key 并收起后，自动新增 N 行，且每行默认选中对应 Key 的第一个 Value。
    - 同一 Key 下只能选中一个 Value。
    - 当前版本不提供批量补齐交互。

### 模块 7：标签视图

- 业务功能：展示标签元数据、命中 API 数量，并支持删除标签。
- 推荐组件：`Table` + `Modal.confirm`
 - 关键规则：
   - 表格上方不展示额外 section title。
   - 操作列包含“编辑”和“删除”两个入口。

## 组件映射清单

- 页面框架：`PageHeader.PageHeaderPro`、`Tabs`
- 筛选：`Select`、`Input`、`Button`
- 列表：`Table`、`Link`、`Tag`、`Tooltip`
- 反馈：`Alert`、`Message`、`Modal.confirm`
- 批量操作：`FixedFooter`
- 批量打标：`Modal`、`Radio.Group`

## 关键交互闭环清单

- 勾选 1 个或多个 API 后，显示底部批量操作栏。
- 点击“批量打标”后，弹窗默认进入“批量移除标签”模式。
- 切换到“批量移除标签”时，展示当前勾选 API 的标签状态，并允许选择待移除标签。
- 切换到“批量新增标签”时，仅展示添加标签区域，并允许在方案 A / 方案 B / 方案 C / 方案 D 间切换。
- 在“添加标签”区域切换 Value 时，按 Key 暂存新增标签；方案 B 和方案 D 支持多行逐项编辑，方案 D 新增行时默认回填该 Key 的第一个 Value。
- 点击“确认应用”后，将变更同步写入所有选中 API，并刷新 API 视图、标签视图与筛选项。

## 异常与兜底

- 未选中 API 时，不展示批量操作栏。
- 全部勾选 API 均未打标时，“批量移除标签”模式展示空提示。
- 选中数量超过单页条数时，弹窗顶部增加“包含跨页 API”提示。
- 提交失败时通过 `Message.error` 给出可操作错误信息。
