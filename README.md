# TOD Starter

基于 ve-o 设计规范的快速启动包。内置 `ve_o_design_tod` Skill，在 Trae IDE 中打开即可通过 AI 生成标准页面。

## 使用方式

1. 获取本项目（clone / 解压）
2. 确认 Node.js >= 18
3. `pnpm install`
4. `pnpm dev`（默认端口 3099）
5. 在 Trae IDE 中打开本目录，输入页面需求即可触发 skill 生成

## 技术栈

React 18 + @tod-m/materials + Tailwind CSS 3.4 + Webpack 5（@cloudcli/scripts）
